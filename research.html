Research Areas

We develop principled techniques and tools across programming languages, software engineering, and cybersecurity to make software fast, reliable, and secure.

🔬

Program Analysis and Verification

Proving software correctness and eliminating deep vulnerabilities. We develop scalable static and dynamic analyses—encompassing path-sensitive value flow, context-sensitive alias analysis, numerical abstract interpretation, concurrency analysis, and directed fuzzing across complex codebases.

Path-Sensitive Analysis

Path-sensitive sparse value-flow analysis, fused analyses without path explosion, and parallel collection of realizable conditions.

Pointer & Alias Analysis

Modular and scalable pointer analysis for C/C++ and Python, SIMD-accelerated bit-vectors, and offline compiler simplifications.

Numerical Analysis

Numerical abstract interpretation, combined bit-level and word-level abstractions, and invariant inference.

Concurrency & Value-Flow

Detecting subtle concurrency bugs, inter-thread data races, and lock misuse vulnerabilities in systems code.

Directed Fuzzing

Provable path pruning, polyhedral abstraction, and multi-target directed greybox fuzzing for vulnerability discovery.

Associated Systems: lotus pyflow InvFinder
⚙️

Program Synthesis and Optimization

Automatically transforming specifications into optimized, production-ready code. We combine formal methods with AI/LLMs to synthesize provably correct code translators, intermediate representations, and optimal compiler optimization hints to maximize software performance.

Compiler Hint Synthesis

LLM-based compiler hint synthesis framework to guide compiler transformation passes and performance tuning.

IR & Code Translation

Empowering version compatibility and verified model synchronization via formal bidirectional transformation.

Container & Structure Synthesis

Complexity-guided container replacement synthesis and data structure optimization for high-performance applications.

Equivalence Verification

Verifying semantic equivalence of data constraints and synthesized program transformations in mission-critical systems.

Associated Systems: hintpilot RepoAudit++ lotus
🧩

Logic and Automated Reasoning

Solving complex mathematical and verification challenges beyond human reach. We advance automated reasoning by developing fast decision procedures, constraint solving algorithms (bit-vectors, strings, non-linear arithmetic), and symbolic automata models that empower modern theorem proving.

Constraint Solving (SMT)

High-performance decision procedures for bit-vectors, strings, floating-point, arrays, and theory combinations.

Symbolic Automata

Precise symbolic automata models and extended regular expression reasoning for stateful software verification.

SMT Simplifications

Compiler optimization-based formula simplifications and learned splitting heuristics for accelerated parallel solving.

First-Order Decision Procedures

Mechanized deduction algorithms and efficient decision procedures underlying software model checking.

Associated Systems: aria InvFinder
