Research Areas

🔬

Program Analysis and Verification

Proving software correctness and eliminating vulnerabilities through scalable static and dynamic analyses—including path-sensitive value flow, alias analysis, numerical abstract interpretation, concurrency, and directed fuzzing.

⚙️

Program Synthesis and Optimization

Transforming specifications into optimized code. We combine formal methods and AI/LLMs to synthesize provably correct code translators, intermediate representations, and compiler optimization hints to maximize software performance.

🧩

Logic and Automated Reasoning

Solving complex mathematical and verification challenges. We develop fast decision procedures, high-performance constraint solvers (bit-vectors, strings, non-linear arithmetic), and symbolic automata models for automated deduction.
