Open Source Software

Our tools are available on GitHub

lotus

C++

A program analysis, verification, and optimization framework built on LLVM. Integrates path-sensitive analysis, alias analysis, and numerical analysis.

Verification LLVM Static Analysis

efmc

SMT

SMT-based software model checker with multiple verification engines including template-based verification, Houdini, k-induction, and IC3/PDR.

Model Checking SMT Verification

aria

Python

Library for constraint solving, theorem proving, and symbolic computation. Powers various program analysis and verification tools.

SMT Symbolic Computation Reasoning

pyflow

Python

Static analysis framework for Python with dependence graph construction, shape analysis, code optimization, and bug checking.

Static Analysis Python Dependence Analysis

veripy

Python

Auto-active verifier for Python programs with symbolic execution and invariant inference.

Verification Python Symbolic Execution

jsflow

Python

JavaScript static and dynamic analysis tool for vulnerability detection and exploit generation.

JavaScript Security Dynamic Analysis
